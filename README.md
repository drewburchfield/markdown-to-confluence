## Status: archived (marketplace)

**Not listed** in the not-my-job marketplace catalog as of marketplace 2.5.0. This repo stays public for clone/URL install if you still need Markdown → Confluence Storage Format conversion.

## What it does

Converts standard Markdown to Confluence Storage Format (XHTML-based XML). Handles code blocks with syntax highlighting, tables, lists, links, and images. Includes a bundled Python conversion script.

## Install (from this repo, not marketplace)

```bash
git clone https://github.com/drewburchfield/markdown-to-confluence.git
```
